1 · 출정 조건

원정 정보와 보유 장비

이미지는 이 브라우저 세션에서만 분석에 전달되며 저장하지 않습니다. API 키는 서버 환경변수에만 보관됩니다.

2 · 영웅 4명

클릭한 열에 붙여넣기

4열 → 3열 → 2열 → 1열 순서. 슬롯을 클릭한 뒤 Ctrl + V, 파일 선택 또는 끌어놓기를 사용하세요.

3 · 보유 장신구

여러 장을 차례로 추가

인벤토리 화면을 여러 번 붙여넣어도 됩니다. 같은 장신구가 겹쳐 보이면 분석 시 수량을 보수적으로 처리합니다.

    영웅 캡처 네 장을 넣으면 분석할 수 있습니다.

    분석 오류가 나도 입력한 이미지와 조건은 유지되며 바로 재시도할 수 있습니다.

    출처 · 검증 일자

    바닐라·Crimson Court·Color of Madness는 나무위키와 Darkest Dungeon Wiki를 교차 확인했습니다. 길이별 보급품·적 타입·상태이상 상성·보스 표는 공식 커뮤니티 위키를 기준으로 했고, 기벽 고정 분류는 나무위키의 6장 구성을 바탕으로 했습니다. 보스 이미지는 출처가 확인된 인게임 기반 파일을 ZIP 내부에 포함했습니다. Sunward Isles는 나무위키가 연결한 한국어 실측 기록과 Steam 가이드를 함께 확인했습니다. 유지보수용 세부 검증 기록은 data/verification-report.json에 분리했습니다.
