# Darkest Dungeon 1 Curio Field Guide

기물·기벽·보스 가이드와 출정 세팅 추천은 `index.html`을 바로 열어도 동작합니다. 출정 탭은 지역과 1~4열 영웅을 선택하면 추천 스킬 4개를 즉시 보여 주며, 한 열 이상을 비운 뒤 조합 추천을 누르면 비어 있는 열의 후보를 순서대로 채웁니다. API 키·이미지 업로드·장신구 분석은 사용하지 않습니다.

## 실행

그대로 파일을 열어도 됩니다. 로컬 서버로 열고 싶으면 Node.js 18 이상에서 아래처럼 실행합니다.

```powershell
npm start
```

그 뒤 `http://127.0.0.1:4173`을 엽니다. 모든 추천 데이터는 파일 안에 들어 있으며 외부 서비스나 브라우저 저장소를 사용하지 않습니다.

## 점검

```powershell
npm run check-assets
npm run check
```

`data/verification-report.json`에는 2026-10-30 기준의 내용 검증 범위와, 확인 불가/부분 확인 모드 항목이 정리되어 있습니다. 출정 추천에는 Fire's Edge의 도망자와 결투가도 포함되며, 결투가는 게임 규칙대로 7개 전투 스킬을 모두 장착하는 것으로 표시합니다.
